# fursenko-marketplace

## What is this
A Claude Code plugin marketplace for developing the Kolo app (Expo/React Native). It hosts kolo-toolkit — scaffolding and guardrails for a feature-first architecture.

## How to add it in Claude Code

## Available plugins
- **kolo-toolkit** (1.0.0) — scaffold a new Bounded Context, scaffold a screen/flow, and protect .env files via a PreToolUse hook.

## Maintainers
- Ludmila Fursenko

## How to contribute
Fork the repo, add your plugin under `plugins/`, update `marketplace.json`, and open a PR. The `validate-plugins` CI must be green before merge.
